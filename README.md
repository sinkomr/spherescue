# Tetrisphere Practice Environment

A browser-based 3D shape rotation practice environment inspired by the N64 game Tetrisphere. This is a training tool focused on spatial reasoning and shape rotation skills.

## Features

- **3D Spherical Block Structure**: A sphere-like shape made up of colorful blocks
- **Free Camera Rotation**: Drag to rotate your view around the shape
- **Interactive Blocks**: Click blocks to remove them from the structure
- **Shape Rotation**: Rotate the shape itself using arrow keys
- **Zoom Control**: Scroll to zoom in and out
- **Auto-Rotation**: Toggle automatic rotation with spacebar
- **Visual Effects**: Smooth animations, lighting, and block removal effects

## Controls

- **Mouse Drag**: Rotate camera around the shape
- **Mouse Scroll**: Zoom in/out
- **Click**: Remove individual blocks
- **Arrow Keys**: Rotate the shape (↑ ↓ ← →)
- **Spacebar**: Toggle auto-rotation
- **Reset Button**: Regenerate the shape

## How to Use

1. Open `index.html` in a modern web browser
2. The 3D environment will load automatically
3. Practice spatial reasoning by:
   - Rotating the camera to view different angles
   - Identifying and removing specific blocks
   - Using arrow keys to orient the shape
   - Observing how the structure changes as blocks are removed

## Technical Details

- Built with Three.js for 3D rendering
- Pure vanilla JavaScript (no framework dependencies)
- Responsive design that adapts to window size
- Smooth 60fps animations
- Dynamic lighting and material effects

## No Gameplay Elements

This is purely a practice environment with no:
- Scores or points
- Timers or countdowns
- Objectives or goals
- Bonuses or power-ups

Focus entirely on developing your spatial reasoning and shape rotation skills.
